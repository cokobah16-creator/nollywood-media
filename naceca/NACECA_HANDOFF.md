## What NACECA is

A cinematic, cel-shaded, third-person tactical-investigation web game grounded in modern Nigeria. Built in Three.js (r128) — runs in any modern browser, no install. The protagonist is Agent Kelechi, a rookie officer in the fictional National Anti-Corruption & Economic Crimes Agency (NACECA), uncovering a ransom-laundering ring that runs from Lagos cyber-syndicates through Delta riverbank handlers into political compounds.

This is a **portfolio piece** for Emeke's nollywood-media GitHub. It's not commercial — it's a serious vertical slice meant to demonstrate range to grant officers, partners, and collaborators (animators, voice cast, narrative consultants).

**Status:** vertical slice playable. Six missions playable end-to-end. Twelve-mission campaign scaffolded.

### Missions playable

1. **HQ Briefing (Lagos)** — onboarding, cdr Adaeze briefs the case
2. **Lagos Market Patrol** — informant interaction with Tunde, KC the teen runner, intel-gathering
3. **Lekki Mansion Raid** — night ops, rescued child, bribe attempt with branching consequences
4. **Benin Bypass Checkpoint** — joint operation with state command, VIN tampering puzzle
5. **Ozalla Forest Shrine** — cultural-respect mechanic with three branches (negotiate, force, leave for warrant)
6. **Asaba Warehouse** — moral choice between chasing the runner Ifeanyi vs rescuing Tobi from a burning office

### Distinctive systems

- **Evidence Board** — Tab-key corkboard overlay where players drag-link suspects, evidence, and locations to assemble the conspiracy. INTEL ≥ 50/70/80/90 unlocks warrant tiers
- **Branching Headlines** — every mission ends with a tomorrow's-headline screen drawn from the player's actual decisions
- **Reputation Triad** — INTEGRITY × PUBLIC TRUST × AGENCY FAVOUR, all tracked separately
- **Skill Tree** — three branches (Tactician, Negotiator, Forensics) with four nodes each
- **Cultural respect** — wrong choices in Ozalla lose evidence and turn the village against you

The architecture is a modular source tree (`src/**/*.js`) that gets concatenated by `build.py` in dependency order into `src/_bundle.js`, which is then folded into `naceca.html` for the single-file build.

## Critical detail — `.nojekyll` placement

GitHub Pages runs Jekyll by default. Jekyll silently filters out files starting with `_` (underscore). NACECA's bundle is named `src/_bundle.js`. **Without a `.nojekyll` file at the repo root, the bundle gets stripped and the game silently fails to load on Pages — even though it works fine when opened locally.**

When you copy `naceca-repo/` into `/naceca/` subfolder of `nollywood-media`, the `.nojekyll` will end up at `/nollywood-media/naceca/.nojekyll`. **That is not enough.** Move it to `/nollywood-media/.nojekyll` so it applies repo-wide.

The `deploy.sh` script handles this automatically.

## Architecture notes for ongoing iteration

If Emeke wants to add a Mission 7, change a portrait, or modify the music system, here's how the pieces connect:

### Adding a new mission

1. Add the mission entry to `naceca/src/config/missions.js`
2. Create a new scene builder in `naceca/src/scenes/m7_yourscene.js` following the pattern of `asaba.js`
3. Wire the scene routing in `naceca/src/systems/mission_flow.js` `loadMission()` switch
4. Add ambient + music cues: `startAmbient('yourscene')` in `audio.js`, `musicForScene('m7')` mapping
5. Run `python3 naceca/build.py` to rebuild the bundle and `naceca.html`
6. Test locally via `python3 -m http.server 8080` then open `localhost:8080/naceca/index.html`
7. Commit and push — GitHub Pages auto-redeploys

### Swapping a portrait

1. Drop a 256×256 PNG into `naceca/src/assets/portraits/your_character.png`
2. Add an entry to `PORTRAIT_MAP` in `naceca/src/systems/dialogue_system.js`:
   ```js
   your_speaker_key: 'your_character',
   ```
3. Run `python3 naceca/encode_assets.py` to base64-encode the new asset
4. Run `python3 naceca/build.py` to rebuild
5. Commit + push

### Adding a music track

1. Drop the MP3 into `naceca/src/assets/music/your_track.mp3`
2. Add a catalog entry in `naceca/src/systems/audio.js` `MUSIC` object:
   ```js
   your_track: 'assets/music/your_track.mp3',
   // OR for variants:
   your_track: ['assets/music/your_track_v1.mp3', 'assets/music/your_track_v2.mp3'],
   ```
3. Call `playMusic('your_track')` from wherever the cue should fire (or extend `musicForScene()`)
4. Run `python3 naceca/build.py` (it copies music to `assets/music/` next to `naceca.html`)
5. Commit + push
