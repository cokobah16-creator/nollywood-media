# NACECA v12 — source recovered from the published page · 7 Oct 2026

Cumulative against main @ ef99332 (v8.1). Carries v9, v10, v11 and v12.

## Where this came from
v9–v11 were published without their source reaching GitHub, and v12 arrived as a
patch layer (`apply_v12.py` + `v12/`) written against that unpublished base, so it
could not be applied to main. The source here was split back out of the published
v12 `naceca.html` using the module markers build.py writes.

Rebuilding this tree reproduces that page byte-for-byte, except the same two
module header labels noted in SYNC-2026-10-07-art-pass-merge.md.

## What changed in the tree
- New modules: `systems/traffic.js`, `systems/onboarding.js`, `scenes/prologue.js`.
- `systems/people_art_pass.js` now loads before `systems/npc_cast.js` (published order).
- `systems/art_pass_v8.js` now also holds code the published page placed in the same
  module: `systems/envart.js` and per-scene overrides (v9), `systems/vehicles_paint.js`
  and `systems/vehicles.js` (v10), `systems/minigames.js` and `systems/sidequests.js` (v11).
  Their boundaries are comments only, so they were kept together rather than guessed apart.
- v12's 16 text fixes (Mushin cold open, blue-shirt case board, Underworld Heat,
  invented newspapers and bank) are now in the source modules themselves.
- `src/v12/` holds the v12 modules and stylesheet, identical to the v12 source zip.
  build.py appends them before `</body>`, the way `apply_v12.py` did, so
  `apply_v12.py` is no longer needed.

## Network
The playtest log (`v12_pt.js`) stays on the device unless `V12.PT_ENDPOINT` is set.
Sharing uses the system share sheet or a wa.me link, only when the player taps it.
Voice-over (`v12_vo.js`) only checks for local `vo/` files.
