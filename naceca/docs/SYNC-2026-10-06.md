# NACECA sync — 6 Oct 2026

Brings `cokobah16-creator/nollywood-media` up to the build published at
https://claude.ai/artifact/NpUzGu8gAiCY75579i9nNX

## What changed

| File | Change |
|---|---|
| `naceca/src/assets/_music_inline.js` | **New.** The six soundtrack keys (title, ambient_lagos, stealth, investigation, chase, victory) as base64 MP3 at 80 kbps, one variant each. |
| `naceca/src/systems/audio.js` | `_resolveMusicUrl()` uses the inlined tracks first (decoded once to a `blob:` URL); falls back to `assets/music/*.mp3` when the module is absent. |
| `naceca/src/systems/engine.js` | Click-and-drag camera when pointer lock is unavailable (embedded frames). Touch camera-drag ignored while any screen is open. |
| `naceca/src/systems/dialogue_system.js` | Tap/click a line to finish the typewriter; tap again to advance. `skipTypewriter()`, `bindDialogueTap()`. |
| `naceca/src/systems/boot.js` | Calls `bindDialogueTap()` on load. |
| `naceca/src/systems/evidence_board.js` | Strings drawn from real card geometry (pin to pin); redraw after the overlay is visible and on resize; cards re-rendered without destroying the SVG. |
| `naceca/src/config/evidence_board.js` | Middle-column card positions spread so Ledger / Laptop / Cash / Wallet no longer overlap. |
| `naceca/index.html` | Top-left HUD cluster wrapped in `.hud-topleft` (panel + pills can't collide); key hints in pills/continue wrapped in `.k`; strings SVG moved inside `#eb-cork`; instructions bar moved under the board. |
| `naceca/styles.css` | Safe-area padding; compact touch HUD; scrollable overlays on phones; evidence board panning; label/button fixes. |
| `naceca/build.py` | Loads `assets/_music_inline.js`; `ROOT` resolved from the script's own path (no hard-coded container path). |
| `naceca/src/_bundle.js`, `naceca/naceca.html` | Regenerated by `build.py`. |

`assets/music/*.mp3` stays in the repo — the dev entry (`index.html`) and any
build without the inline module still use it.

## Apply it (terminal)

```bash
cd /path/to/nollywood-media
unzip -o /path/to/naceca-sync.zip -d .        # overwrites files under naceca/
cd naceca && python3 build.py && cd ..        # optional: proves the bundle parses locally
git add naceca
git commit -m "NACECA: inline soundtrack, phone HUD, tap-to-continue dialogue, evidence board fixes"
git push origin main
```

GitHub Pages redeploys in a minute or two:
https://cokobah16-creator.github.io/nollywood-media/naceca/naceca.html

`naceca-changes.patch` (shipped alongside the zip, not inside it) is the same change as a reviewable `git diff` of the
hand-edited files only (no generated or base64 files). `git apply --check`
passes against the current `main`.
