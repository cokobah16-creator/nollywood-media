# NACECA — Phase 1 (release stability) · 6 Oct 2026

Includes the Mission 7 drop (see SYNC-2026-10-06-m7.md) if it hasn't been pushed yet.

## Fixed
- **Mission 5 soft-lock.** Pa Eze's "access granted" lines carried their flag inside a
  line-level `effect` that nothing applied, and `S.game.flags` didn't exist. Line effects now
  apply when the line is shown; story flags live in `S.game.flags` (choice flags mirrored there
  too, so the shrine headlines branch correctly).
- **Evidence counter (e.g. 7/3).** The HUD and aftermath now count evidence for *this*
  operation; lifetime evidence is deduplicated by id, and replays earn reduced XP.
  Evidence targets corrected: M2 1, M3 3, M7 3.
- **Aftermath stats** (arrests, civilians, force, intel, XP) are per operation, not lifetime.
- **Camera clipping.** Ray-cast camera collision against solid scenery; snaps in, eases out.
- **Continue / Load** only resumed missions 1–3 and dropped everyone else back to M1. They now
  resume the first unfinished playable mission.
- **Old saves** merge section-by-section, so saves from earlier builds gain new fields.

## New
- `tools/playthrough.py` — plays all 7 missions to the end under 3 choice policies
  (21 runs). Current result: 21/21 complete, zero JS errors.
